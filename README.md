## :dart: O guia para alavancar a sua carreira

> Apache Cordova é o framework que originou o desenvolvimento mobile híbrido: ele empacota uma aplicação web (HTML, CSS, JavaScript) dentro de um "container" nativo para iOS e Android, dando acesso a APIs do aparelho — câmera, geolocalização, arquivos, notificações — através de plugins. Foi a base técnica sobre a qual o Ionic e centenas de apps corporativos foram construídos entre 2012 e meados dos anos 2020. Hoje o Cordova é uma tecnologia **legada**: o próprio time do Ionic recomenda o [Capacitor](https://capacitorjs.com/) como sucessor para projetos novos, e a grande maioria dos tutoriais recentes fala em "migrar de Cordova" em vez de "aprender Cordova". Ainda assim, o projeto segue mantido pela Apache Software Foundation (com releases em 2025 e 2026) e milhares de aplicações em produção — bancos, varejo, apps corporativos internos — continuam rodando sobre ele. Este guia é para quem precisa **manter, dar suporte ou migrar** um app Cordova existente: reúne a documentação oficial, o caminho de migração para Capacitor, ferramentas, comunidades e um capítulo de IA na prática focado exatamente nesse cenário.

## 🗺️ Roadmap

Cordova não tem um roadmap visual estilo roadmap.sh — o "roadmap" real, hoje, é entender como o projeto funciona e para onde o ecossistema está indo:

- [The Command-Line Interface (Cordova CLI Guide)](https://cordova.apache.org/docs/en/latest/guide/cli/index.html) — Guia oficial do fluxo básico: criar projeto, adicionar plataformas (`android`/`ios`), instalar plugins, buildar e rodar.
- [Overview (Cordova Guide)](https://cordova.apache.org/docs/en/latest/guide/overview/index.html) — Explicação oficial de como o Cordova funciona por baixo dos panos: o WebView, a ponte nativa e o modelo de plugins.
- [What to Read Next](https://cordova.apache.org/docs/en/latest/guide/next/index.html) — Página oficial de "próximos passos" depois do básico: plataformas, plugins, distribuição nas lojas.
- [Migrating from Cordova to Capacitor (Capacitor Docs)](https://capacitorjs.com/docs/cordova/migrating-from-cordova-to-capacitor) — O roadmap real para quem já tem um app Cordova em produção: guia oficial passo a passo de migração para o Capacitor, mantendo os plugins existentes.

## 🤖 IA na prática

Cordova é o cenário perfeito para IA em um papel bem específico: **não** o de ensinar a tecnologia do zero, mas o de ajudar a entender, auditar e migrar código legado que ninguém no time escreveu.

**Para entender e manter um app existente**
- Cole o `config.xml` do projeto e peça para a IA explicar, seção por seção, o que cada `<plugin>`, `<preference>` e `<access origin>` faz — é comum herdar um projeto Cordova sem documentação nenhuma.
- Peça para listar, a partir do `package.json`/`config.xml`, quais plugins estão instalados e se cada um tem equivalente mantido no ecossistema Capacitor (compare com a [documentação de compatibilidade](https://capacitorjs.com/docs/cordova)).
- Cole um erro de build do Xcode ou do Android Studio junto com a versão do `cordova-android`/`cordova-ios` instalada — problemas de compatibilidade entre versões antigas de plugins e SDKs novos do Android/iOS são a causa mais comum de builds quebrados em projetos legados.

**Para planejar uma migração para Capacitor**
- Use o [guia oficial de migração](https://capacitorjs.com/docs/cordova/migrating-from-cordova-to-capacitor) como referência e peça à IA para gerar um checklist específico do seu projeto, cruzando a lista de plugins instalados com o que precisa ser trocado.
- Use [GitHub Copilot](https://github.com/features/copilot), [Cursor](https://cursor.com/) ou [Claude Code](https://code.claude.com/docs/en/overview) para reescrever, arquivo por arquivo, chamadas de plugins de Cordova pelas APIs equivalentes do Capacitor — é um trabalho mecânico e repetitivo em que agentes de código rendem bem.
- O [Model Context Protocol](https://modelcontextprotocol.io/) permite conectar ferramentas externas a assistentes de IA; a [Capawesome já expõe um servidor MCP](https://capawesome.io/docs/ai/mcp/) para builds, deploys e gestão de apps Capacitor, e o [awesome-ionic-mcp](https://github.com/Tommertom/awesome-ionic-mcp) reúne outros servidores MCP do ecossistema, úteis também durante a migração.

**Limites e boas práticas**
- IA erra com frequência em nomes de plugins antigos e comandos de CLI descontinuados — o Cordova mudou bastante entre 2015 e 2026, e o modelo pode misturar sintaxe de versões diferentes. Confirme sempre na [documentação oficial](https://cordova.apache.org/docs/en/latest/).
- Não cole certificados de assinatura (`.p12`, `.keystore`, provisioning profiles) nem chaves de API de produção em ferramentas de IA sem verificar a política de privacidade da sua empresa.
- Um app Cordova antigo em produção geralmente tem clientes reais dependendo dele — qualquer mudança sugerida por IA em código nativo (plugins customizados em Java/Kotlin ou Swift/Objective-C) precisa ser revisada por alguém com experiência na plataforma antes de ir para produção.
